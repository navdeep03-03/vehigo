# Vehigo Website

A complete static one-page website for Vehigo, a private fleet compliance and challan-management platform concept.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual system and components
- `app.js` - navigation, accessible tabs, vehicle lookup, copy button, local lead capture, and CSV export
- `assets/` - original Vehigo mark and dashboard preview artwork

Open `index.html` in a browser to preview locally.

## Demo Data

The lead form stores requests in `localStorage` and exports them as `vehigo-demo-requests.csv`. No backend is required for the static demo.
